# [Production Pipelines for Interactive Platforms](https://conference.blender.org/2023/presentations/1814/)

Tablet apps for mechanical configuration, consumer facing WebGL experiences, and real-time automotive HMI designs all have something common: they can benefit from adding Blender to the production pipeline.

John Einselen, motion design technical director at Launch by NTT DATA (formerly Vectorform) and Philip McCloskey, 3D lead, will present on how Blender has been adopted as a core part of media production and interactive development workflows. Using client case studies as examples, they will share how a tiny team of technical artists tackle efficiency challenges, along with the free toolsets developed along the way.
